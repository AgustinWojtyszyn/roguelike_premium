# Roguelike Premium — sala de prueba

Godot 4.7. Una sola sala; todo el arte y audio se genera por código.

- PC: WASD + mouse (click dispara), 1/2/3 o rueda/Q/E cambia arma, R reinicia.
- Android (horizontal): stick izquierdo mueve, stick derecho apunta y dispara, botón para cambiar arma.
- Pruebas: `godot --path . -- --bot --god --shots=3,8 --shotdir=/tmp/s --quit=20`
