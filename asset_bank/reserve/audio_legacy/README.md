# Legacy procedural audio (reserve, not compiled)

`sfx_bank_legacy.gd.txt` is the pre-2026-10-10 `audio/sfx_bank.gd` (single-oscillator / one-pole-noise sounds and
chip-style music). It was retired from the runtime because the effects were thin and repetitive (see docs/AUDIO_REBUILD.md).
It is plain code written by this project (no third-party audio), kept only for reference/rollback. Rename to `.gd` to restore.
